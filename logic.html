Modul 1: AI Master Orchestrator & Specialized Agent Swarm

Logika pembagian peran agen AI dan sintesis sinyal multi-domain

Sistem menggunakan arsitektur Multi-Agent Swarm di mana setiap agen memiliki keahlian domain spesifik. Master Orchestrator bertindak sebagai koordinator utama yang menggabungkan seluruh keluaran agen spesialis menjadi rekomendasi keputusan final.

👑 Orchestrator (Master AI) Coordinator

Fungsi: Mengagregasi sinyal dari 6 agen spesialis. Menghitung skor konsensus (*Consensus Score* 0–100) dan menentukan aksi rekomendasi (`STRONG BUY`, `BUY ON WEAKNESS`, `HOLD`, `TAKE PROFIT`, `STOP LOSS`).

Score = (0.25 * Bandarmology) + (0.25 * Fundamental) + (0.20 * Technical) + (0.15 * Macro) + (0.15 * Sentiment)
🕵️‍♂️ Bandarmology Agent Big Money Flow

Fungsi: Menganalisis Broker Summary, aliran dana institusi (*Big Accumulation* vs *Distribution*), serta transaksi *Net Foreign Buy/Sell* harian dan akumulasi 5-Hari.

📊 Fundamental Agent Valuation & Growth

Fungsi: Menilai kesehatan neraca, solvabilitas, rasio profitabilitas (ROE, NPM), serta kalkulasi harga wajar intrinsik (*DCF Fair Value*).

📈 Technical Agent Chart & Price Action

Fungsi: Mengidentifikasi struktur tren (Uptrend/Downtrend/Sideways), level Support/Resistance kritis, pola Candlestick, dan Moving Averages.

🌐 Macro Agent Economy & Sector

Fungsi: Menghubungkan tren suku bunga BI Rate, kurs JISDOR USD/IDR, pergerakan komoditas acuan (Emas, Tembaga, Batu Bara, CPO), dan indeks rotasi sektor BEI.

🛡️ Risk Manager Agent Money Management

Fungsi: Menentukan *Risk/Reward Ratio* (minimal 1:2), alokasi persentase modal per posisi (*Position Sizing* max 10-15%), serta memasang batas ketat *Stop Loss* & *Take Profit*.

Modul 2: Logika Analisa Bandarmology & Foreign Flow

Algoritma konsentrasi broker dan kalkulasi pergerakan uang besar (Big Money)

A. Formula Konsentrasi Broker (Top 1, Top 3, Top 5)

Konsentrasi diukur dari perbandingan jumlah lot yang dibeli oleh Top Buyer terhadap jumlah lot yang dijual oleh Top Seller:

// Algoritma Kalkulasi Net Volume Top Broker
Net Volume Top N = Sum(Lot Buy Top N Broker) - Sum(Lot Sell Top N Broker)
// Penentuan Status Bandarmology:
If (Net Volume Top 1 > 35% Total Vol) ➔ BIG ACCUMULATION
Else If (Net Volume Top 1 > 15% Total Vol) ➔ NORMAL ACCUMULATION
Else If (Net Volume Top 1 < -35% Total Vol) ➔ BIG DISTRIBUTION
Else ➔ NEUTRAL / CROSSING

B. Klasifikasi Broker BEI

  • Broker Asing (F): `ZP` (Maybank), `BK` (J.P. Morgan), `AK` (UBS), `CS` (Credit Suisse), `KZ` (CLSA).
  • Broker Institusi Domestik (D): `OD` (BRI Danareksa), `NI` (BNI Sekuritas), `PD` (Indo Premier).
  • Broker Ritel Domestik (R): `YP` (Mirae Asset), `CC` (Mandiri Sekuritas), `XL` (Stockbit Sekuritas).

Modul 3: Engine Pemantauan Volume Periodik & Anomali RVOL

Penghitungan Relative Volume Ratio & Deteksi Lonjakan Transaksi

A. Rumus Relative Volume Ratio (RVOL)

RVOL membandingkan volume transaksi periode berjalan dengan rata-rata bergerak volume 20-periode (MA20 Volume):

RVOL = Current Volume / MA20(Volume)
// Klasifikasi Tingkat Lonjakan:
• RVOL < 1.3x ➔ Volume Normal (Aktivitas Rutin)
• RVOL 1.3x - 1.8x ➔ Volume Spike Sedang (Perhatian)
• RVOL ≥ 2.0x ➔ VOLUME ANOMALY / BIG SPIKE 🔥

B. Timeframe Support

Intraday (Sesi) Detail transaksi Sesi 1 & Sesi 2 dengan tracker HAKA vs HAKI.
Harian (Daily) Perbandingan volume harian terhadap rata-rata 20 hari bursa.
Mingguan (Weekly) Agregasi volume mingguan untuk analisa akumulasi swing trader.
Bulanan (Monthly) Tren akumulasi institusi jangka panjang (6 bulan terakhir).

Modul 5: Analisa Fundamental & Model Valuasi DCF

Kalkulasi Fair Value intrinsik dan Skor Kesehatan Neraca

A. Pemodelan Discounted Cash Flow (DCF) Simplified

Fair Value DCF = Sum[ FCF_t / (1 + WACC)^t ] + Terminal Value
// Parameter Default:
• WACC (Weighted Average Cost of Capital) = 8.5% - 10.0%
• Terminal Growth Rate (g) = 3.0%
• Margin of Safety (MoS) = (Fair Value - Current Price) / Fair Value * 100%

B. Fundamental Health Score Index (0–100)

Diukur berdasarkan 5 pilar utama:

ROE > 15% Bobot 25%
DER < 1.0x Bobot 20%
NPM > 10% Bobot 20%
PER < Historical Bobot 20%
Div Yield > 4% Bobot 15%

Rotasi 11 Sektor BEI

Memantau aliran rotasi modal harian antar sektor untuk mendeteksi sektor mana yang sedang *Inflow* atau *Outflow*.

Modul 9: Integrasi Google Drive Workspace (`driveService.ts`)

Otentikasi Google OAuth & Sinkronisasi Laporan Riset ke Google Drive

Modul ini memungkinkan pengguna menghubungkan akun Google secara aman untuk mengespor laporan analisis saham BEI directly ke Google Drive:

Alur Otentikasi OAuth (GSI & Firebase Auth):

Pengguna melakukan Sign-in via popup Firebase Auth dengan OAuth Provider Google (`drive` & `drive.file` scopes). Access token disimpan secara terisolasi pada in-memory state aplikasi demi keamanan (*no local storage token leak*).

Rest API Calls & Safegard Konfirmasi:

1. Create File: Mengunggah dokumen riset Markdown (`.md`) via multipart REST API (`upload/drive/v3/files`).
2. Delete File Safeguard: Setiap aksi hapus file mewajibkan konfirmasi modal eksplisit sebelum mengeksekusi HTTP DELETE ke Drive REST API.
